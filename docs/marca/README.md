# Marca Mimba — assets para uso externo (impressão, brindes)

Logo em alta resolução, fundo transparente, prontos pra estampa/impressão.
Gerados a partir da mesma fonte e proporções já usadas no ícone do app
(`mobile/resources/icon.png`) — ver fontes `.svg` nesta pasta pra reeditar.

## Arquivos

| Arquivo | Uso | Resolução |
|---|---|---|
| `mimba-monograma-branco.png` | Monograma "M." branco — pra fundo escuro (camiseta preta/verde) | 1511×1100px |
| `mimba-monograma-verde.png` | Monograma "M." verde (`#4F6B2E`) — pra fundo claro (camiseta branca/creme) | 1511×1100px |
| `mimba-wordmark-branco.png` | Wordmark "Mimba." branco — pra fundo escuro | 2482×538px |
| `mimba-wordmark-verde.png` | Wordmark "Mimba." verde — pra fundo claro | 2482×538px |

Todos com fundo **transparente** e o ponto final sempre em dourado
(`#B8860B`, o `--ouro` oficial da marca — nunca muda de cor).

**Fonte:** Manrope ExtraBold. **Não** usar outra fonte pro "M"/"Mimba" — é a
mesma família (com pesos diferentes por contexto) usada em todo o app.

## Sobre a resolução

Boas pra impressão de camiseta em tamanho normal (até ~30cm de largura em
boa qualidade). Se precisar de algo maior (banner, outdoor), voltar nos
`.svg` fonte e reexportar em resolução maior — são vetoriais, escalam sem
perda.
