## Regras de marca (confirmadas nesta atualização)

- **Ponto final**: sempre um **quadrado de cantos retos** (não é um círculo —
  é o glifo real do "." na Manrope ExtraBold, que é quadrado). Cor sempre
  dourada (`#B8860B` claro / `#E8C567` escuro) — nunca muda.
- **Cor principal da marca**: **Ink** (`#2B2419` claro / `#F0EFE9` escuro) —
  não é mais o verde. Verde (`--campo`, `#4F6B2E`) continua existindo, mas
  como acento pontual, não como cor primária.
- **Fundo escuro** → texto/M em branco.
- **Fundo claro** → texto/M em **ink/preto** (`#2B2419`), não verde.
- **Fonte**: Manrope ExtraBold (mesma família usada no app, pesos variam
  por contexto — ver MIV pra detalhe por componente).
